# Marlin 墨鳞 · 下载

Marlin 是 Windows 上的 Markdown 阅读与编辑器：双击 `.md` 直接看到排好版的文档，按 `E` 就地修改。

这个仓库只放安装包，每个版本都在 [Releases](https://github.com/marlin-md/marlin-releases/releases) 里：

- `Marlin_x.y.z_x64-setup.exe`：安装版，装到当前用户目录，不需要管理员权限。2.0.2 起会自动检查更新
- `Marlin_x.y.z_x64-portable.zip`：便携版，解压即用，设置放在程序旁边的 `data` 文件夹里
- `latest.json`：程序检查更新用的清单（2.0.2 起）

介绍和使用说明见官网：https://marlin-md.github.io/marlin-website/

遇到问题或有建议，请在本仓库的 [Issues](https://github.com/marlin-md/marlin-releases/issues) 里提。
